LINE VOOM Camera — capture, edit, compose

Short-form video · JP · TW · TH

The iOS camera and editing module for LINE VOOM, LINE's short-form video service. I owned the camera tier — session, live preview, screen transitions — and the two technical cores: the Storyboard model holding the whole edit state, and VOOMVideoComposer rendering it to video.

  • Storyboard as a single source of truth for clips, music, dubbing, stickers, filters and volume — serialisable, versioned and migratable.
  • Multi-track video / audio / effects composition, local drafts with recovery, and CDN-delivered templates.
  • Router-based navigation with dependency injection; camera features modularised for reuse in profile and story surfaces.
  • Swift
  • Objective-C
  • AVFoundation
  • Metal
  • Core Image
  • AVMutableComposition
More detail
  • AVFoundation camera session owner (VoomCameraViewController), device-specific formats and resolutions.

  • NSSecureCoding serialisation with schema-version migration.
  • Draft system (LightsDraft, DraftKeyManager) for local drafts and crash recovery.
  • Thread safety between background and main queues; memory tuning for large edits.

2023 · shared library
KBOM
Runtime object lifecycle

KeyBasedObjectManager

iOS runtime library

A runtime manager that stops objects sharing the same key from being created twice or leaking — simplifying the share / release policy for heavy resources like sessions and models in camera and AI features.

  • Key-based register / lookup / release API across Swift and the Objective-C runtime.
  • Weak-reference storage on NSMapTable, guaranteeing no leaks.
  • Thread-safety and concurrency tests with XCTest; adopted by VOOM Camera and other modules.
  • Swift
  • ObjC runtime
  • NSMapTable
  • XCTest
2019 — 2021
Avatar
Launch · architecture

LINE Avatar

Avatar creation · AR camera · iOS

Shipped LINE Avatar on iOS: the creation flow, the customisation view, a face-tracking AR camera, a photo booth and face detection — built on LINE's avatar graphics and camera engine.

  • Every view model kept its own copy of the avatar, and they drifted out of sync. I introduced MVVM with one shared data model all view models refer to — one avatar, one source of truth.
  • Built the face AR camera and face detection view on the in-house engine.
  • Swift
  • MVVM
  • AR camera
  • Face detection
